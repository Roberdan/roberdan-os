## roberdan-os — canonical behavior (default, every session)

Full canon: `~/GitHub/roberdan-os/AGENTS.md` — read it for any non-trivial work (default =
loop + roberto-mode; twin for voice; human gates never automated). Under `~/GitHub` the
`~/GitHub/CLAUDE.md` pointer already carries the same rules in detail.

**Talk to Roberto in this fixed format — every reply, every project, no exceptions**
(accessibility commitment, not a style preference; inlined here because a pointer does not
bind when the canon file is not loaded):

- **Stato** — where the work is now, one line per thing. Every line says whether it was
  proven: "fatto e provato" or "fatto, non ancora provato". Never "done" without which.
- **Sto facendo** — what is running right now. Or "Nulla".
- **Manca** — what is left, in order. Or "Nulla".
- **Mi serve da te** — the decision or action you need from him, with your recommendation
  first and marked as such (max 3 options). Or "Nulla".

Delete a section that is empty; never fill it with "N/A". No unexplained jargon — say what a
term *means* in the same sentence. Max ~6 lines before any detail (commands, paths, numbers),
which always goes last. "Non capisco" is feedback on the writing: re-say it differently.
