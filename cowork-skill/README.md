# cowork-skill — the canon packaged for Microsoft 365 Copilot Cowork

`roberdan-os/` is the skill package for **M365 Copilot Cowork**
(the Cowork tab of the Microsoft 365 Copilot app) — not GitHub Copilot. Different surface,
different shape: Cowork works on documents, mail, meetings and Teams, with no git, no CI and
no terminal, so the engineering evidence forms (commit SHA, PR, green CI) are replaced by the
ones that exist there — the artifact re-opened and checked, the number traced to its source,
the tool failure reported as a failure rather than as an empty result.

It also carries the half the other exports can't: **how to use the tenant**. Gather from
WorkIQ / Teams / Outlook / meetings / OneDrive before answering, because the named failure
mode on this surface is answering from general knowledge when the answer was in his own data;
produce real Word/Excel/deck artifacts instead of chat text; name the source of every figure.

Hand-derived from `behavior/roberto-mode.md`, `identity/voice.md`,
`behavior/thinking-toolkit.md`, `rules/constitution.md` and the human gates in `AGENTS.md`.
**Not generated by `bin/sync.sh`** — re-derive by hand if the canon changes meaningfully.

Deliberately layered: `SKILL.md` is the core and stands alone; `VALUES.md`, `THINKING.md`,
`ADVISORS.md` and `VOICE.md` carry the depth (values + 8 articles + manifesto, the full
reasoning repertoire, the agent-set as hats with the board's lenses, the voice contract). The
core says explicitly what to do if a companion file can't be read — say so, don't pretend.

## Install (two ways, pick one)

**A — OneDrive folder (auto-detected).** Put the whole folder at:

```
OneDrive/Documents/Cowork/Skills/roberdan-os/
    SKILL.md  VALUES.md  THINKING.md  ADVISORS.md  VOICE.md
```

Cowork picks up every skill under `Documents/Cowork/Skills/<name>/`. No admin needed.

**B — Upload from the app.** Cowork → **Personalizza** (left rail) → **Skill** → *Aggiungi /
Carica* → select `SKILL.md`, or a zip of the whole `roberdan-os/` folder if you want the
companion files to travel with it.

Then open a Cowork task: the skill loads by itself when the request matches its `description`.
It appears under **Competenze e plug-in** in the right-hand workspace panel — that panel is
the check that it's actually active.
