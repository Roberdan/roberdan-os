## Novelties + impact

1. **The model map in `bin/sync.sh` was two generations stale.** `copilot_model()` emitted
   `claude-opus-4.5` / `claude-sonnet-4.5` while Copilot on this machine runs `claude-opus-5`
   and offers `claude-sonnet-5`. Every Copilot-native agent `bin/sync.sh` generates
   (`~/.copilot/agents/*.md`) therefore pinned a model a generation and a half old. Because an
   unavailable id degrades silently to the session model, nothing ever failed loudly — which
   is exactly why it went unnoticed for months. **APPLIED.**

   Worth writing down: **Copilot's id scheme is not Anthropic's.** Copilot uses dots for the
   4.x line (`claude-opus-4.8`) and no separator for the 5 line (`claude-opus-5`), where
   Anthropic writes `claude-opus-4-8` with dashes and `claude-opus-5` the same. Guessing the
   dotted form for the 5 line would have produced a silently-degrading id.

2. **Haiku is not stale.** `claude-haiku-4.5` is still Copilot's newest Haiku (Anthropic has
   shipped no newer Haiku). That row stays as it is — checked, not assumed.

3. **Everything else this week is admin/governance or model-catalogue, not a repo change:**
   remote control limited to managed devices, default model enablement for Business/Enterprise,
   app usage metrics rollups, Grok 4.5 availability. Recorded as declined.

4. **"Copilot code review: Agent skills and MCP now GA"** — Copilot's own review product
   gaining skills/MCP. roberdan-os keeps review owned by its `review` skill with `@rex` and
   `@thor` as the gates; the two do not compose. Declined, same reasoning as the 07-25 pass.

## Suggested patch (draft only → APPLIED for item 1)

- `bin/sync.sh` `copilot_model()`: `opus` → `claude-opus-5`, `sonnet` → `claude-sonnet-5`,
  `haiku` unchanged at `claude-haiku-4.5`. The canonical model tier in `agents/*.md` is
  untouched — only the Copilot-side rendering changes.
  Citation: `~/.copilot/session-state/*/events.jsonl`, GitHub Copilot CLI 1.0.77, observed
  2026-07-31; and https://github.blog/changelog/2026-07-24-claude-opus-5-is-now-available-in-github-copilot (2026-07-24).
- `test/test-copilot-adapter.sh`: the two model assertions matched the **family**
  (`^model: claude-opus`), so they stayed green through the entire period the map was stale —
  a prefix match cannot see staleness, which is the only failure this row has ever had. Now
  pinned to the exact id. Mutation proof recorded: restoring `claude-opus-4.5` turns the
  assertion red; the current map turns it green.
