## Novelties + impact

Nothing in this window requires a roberdan-os change. The 2026.07.31 release is product
surface — Warp's own UI, its Oz agent platform, and its cloud runners:

1. **Custom model endpoints can now select an OpenAI Chat Completions, OpenAI Responses or
   Anthropic Messages schema** (#13938). Relevant only to someone routing Warp at a custom
   endpoint; roberdan-os does not.
2. **Agent execution profiles configurable from settings files for all users** (#14418), and
   **`oz` CLI can set a named agent's prompt** (#14261). Warp's agent system is separate from
   the canon's; `AGENTS.md` is already read natively, and nothing here changes that path.
3. **MCP tool confirmations now name the tool and its server** (#14298). A UI improvement on
   Warp's side; the canon's MCP posture (least privilege, reviewed servers) is unaffected.
4. **`warpctrl` can no longer spawn caller-chosen shell binaries** (#14158) and a bundled
   dependency was updated for **CVE-2026-50185** (#13357). Both are Warp fixing Warp — good
   news, no action on our side.
5. Remaining entries are editor, recording, prompt-rendering and worktree-path fixes.
