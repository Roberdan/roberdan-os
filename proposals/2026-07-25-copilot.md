## Novelties + impact
1. Claude Opus 5 is available in Copilot CLI, cloud agent, app, VS Code, JetBrains, and other Copilot surfaces. `bin/sync.sh` still maps canonical `opus` agents to `claude-opus-4.5`, so Copilot-native custom agents lag the current intended premium model.
2. GitHub MCP Server moved ahead of the next MCP spec and points to official conformance tests. roberdan-os hand-rolls `bus/bus-mcp.py`; that is intentionally narrow, but it has no conformance smoke test.
3. Copilot CLI now has forks, `/rubber-duck`, harness todo lists, better URL rendering, and macOS/Linux path-capitalization fixes; useful, but they do not replace `kb`, `handoff/`, or the existing Copilot extension.
