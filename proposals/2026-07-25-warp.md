## Novelties + impact
1. Warp’s 2026.07.23 release made the headless TUI materially more usable for agent work: generic, file-edit, and shell-command permission requests now surface in the TUI; shell commands are editable before confirmation; the TUI shows shell/cwd/agent-mode status; and Agent Mode output renders Markdown.
2. Warp also enabled Cloud Runners for all users, added `/fast-forward` autoexecute, image attachments, pinned tabs, oh-my-pi integration, and many TUI UX fixes. Those are useful for a human operator, but not all should enter roberdan-os canon.
3. `bin/sync.sh` emits Claude, Copilot, Codex, ChatGPT, and Hermes notes, while README/doctor already treat `warp` as an AGENTS.md-reading CLI. Warp has no generated setup note.

## Suggested patch (draft only)
- Add an `emit_warp` target to `bin/sync.sh` that generates `platforms/warp/README.md`: run Warp from a repo containing `AGENTS.md`, keep TUI permission prompts enabled, do not enable `/fast-forward` autoexecute for guarded roberdan-os work, and use the TUI status line to verify cwd before edits.
